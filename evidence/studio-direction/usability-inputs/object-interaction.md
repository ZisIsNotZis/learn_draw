# Drawing an action between a person and a prop

Use this branch for carrying, grasping, pouring or a mark connecting two separately movable objects.
Current demonstrated scope includes the native compact grip in examples/studio/held_flag.json
and watering_grip.json. A fresh skill-only operator created the original flag, used its named
mounts and refined the thumb without reconstructing the primitive. The person accepted retaining
this graphic hand as a simple preset direction; natural anatomy and arbitrary contact remain
unproven. evidence/studio-grasp-glyph/README.md owns the current sequence. Earlier watering
and rejected mesh studies below retain their diagnostic lessons.

## Establish the action before finish

1. Name the action chain: shoulder -> sleeve -> wrist -> grip -> handle -> vessel -> outlet ->
   stream -> destination. Check each contact and the complete picture. Recognizable nouns can
   still communicate an impossible action: the first watering image had an open palm above a
   suspended can, and the first closed hand still held an almost upright can pouring uphill.
2. Check the direction of weight and flow. Raise the held object when its outlet is below the
   destination; visibly tip the reservoir toward the outlet. A continuous coloured line alone
   does not establish pouring. In Studio's screen convention y grows downward; stroke angle 0
   goes down, 90 right, 180 up. Inspect the real result rather than trusting a remembered angle.
3. Choose a hand pose that serves the contact. The existing open-palm macro works for greeting;
   shortening or placing it above a bar does not turn it into a closed grasp. A bounded flat
   alternative can use one rounded palm/knuckle mass plus a crossing thumb stroke and a short
   finger crease. Keep this small, and judge its actual silhouette. The watering example still
   has crowded grip detail; do not advertise this recipe as a solved anatomical fist.
4. Explain wrap with depth: palm behind the held bar, a crossing thumb/finger in front. Showing
   every part as a single opaque silhouette can hide the very enclosure that communicates grip.
   Verify an actual overlap, wrist direction and a readable load-bearing contact in the image;
   geometric intersection and correct depth order do not by themselves prove a convincing hand.
5. Give the receiving surface a readable opening when it matters. The pot's plain top initially
   made the water look as if it hit a solid vessel. A small soil ellipse and deliberate stem/rim
   depth explain the destination without texture or decorative splash effects. A center mount can coincide with the stem;
   choose an actually visible open patch of soil, using an inspected edge and inward inset when
   appropriate. Automatically preserving the wrong target does not improve the picture.

## Revise the chain without losing its far end

A one-point relation preserves one point and the child's independent angle/size. Tipping the
watering vessel left its handle's free terminal floating until a visible terminal correction
seated it. Moving the gardener moved the held can and water root correctly, but moved the stream's
free end off the stationary soil. These are current tool limits, not a reason to keep the bad pose.

Inspect root/tip and the intended destination in actual images. Correct the free terminal while
its opposite end is pinned; read the clean result and local overlay before acceptance. Reinspect
for a further correction. The independent reframe used a rightward move, then a smaller upward
move after observing that the stream landed too near the front rim. Those amounts are specific
to that picture, not reusable constants. That study used manual correction. Studio now offers separately inspected endpoint bindings
(see the main skill): binding both root and tip derives the chord and follows both named targets.
Use that operation for continuing connections, and inspect the real revised image. It does not
make a general fluid/grip solver or guarantee a physically plausible bend.

A root-object overlay outlines the selected object, not every descendant that may follow it.
Read the whole clean preview after a parent edit. Distinguish explicit colour planes and outlines
from actual support/depth relationships; more marks cannot repair a broken attachment or pour.

## Keep the proven scope visible

The watering study was initially authored as a relational scene; most corrections used public CLI,
and two compound groups used the model API with rendered previews and normal acceptance. It does
not establish a public atomic insertion/replace transaction. The separate operator used only the
previous skill, the supplied scene and public commands to reframe and repair the pour. This proves
a bounded editing loop, not independent generation of the entire illustration from this recipe.
Fresh image review still retains grip ambiguity, stiff pose and inconsistent head/body detail.

## A depth-correct hand can still fail to grasp

The subsequent grasp study tested curved finger tubes, a palm and an opposed thumb,
then an established continuous articulated mesh. More contour detail and different
views did not make the tube hand a useful default. The imported mesh also failed when
posed with arbitrary flexions: skin vertices penetrated the rod, and fresh reviewers
read draped fingers with an unopposed thumb. These are rejected studies, not commands
or a new grasp primitive. Check contact/enclosure and the actual picture before
polishing folds or treating an imported rig as solved anatomy. Keep line art separate
from visibility: numerical fragment boundaries and every mesh edge are not art lines.

## Use the compact native grip for graphic holding

Start with `kind: grip`; its palm, folded pads, opposed thumb and owned handle are computed
together. Use the main skill and scene contract for actual controls and bounds. Inspect wrist,
handle_left/right and dimensions before connecting a sleeve or extending a pole. Rotation can
reverse which named endpoint appears higher: read the actual overlay. The flag operator used
the default shape, then shortened thumb_reach from .90 to .72 through a visible proposal; these
are picture-specific values, not a mandatory recipe. Keep all independent mounts stable.

One-point attachment seats a point, not a cuff edge. Inspect the sleeve tangent and width at
the wrist; a slanted sleeve left a triangular gap in the independent flag. In watering, changing
the sleeve bend aligned its terminal tangent while both endpoints stayed pinned. Match a
continuous pole material across the grip-owned segment and external extensions when the
style calls for one rod; their independent ink colours otherwise create artificial seams.

A two-pinned stream still needs a deliberate curve and taper: align its start tangent to the
nozzle and inspect the soil landing. A can-opening oval was discarded because the arm hid it
into two stray patches. Inspect actual visibility before adding explanatory detail. These are
observed drawing corrections, not automatic contact, orientation-fit or fluid solvers.
