## Visual evidence and disposition

- `01-default`, `02-inner-curve`, `03-reinspect`, `04-ease-back`: first operation record. Two fresh
  image reviewers saw the edit but called the isolated shape leaf/blade-like, the highlight an inlay,
  the local tuck pinched, and the root a sealed cap. Frozen SVGs preserve those historical renders;
  current scene defaults do not reproduce their old treatment.
- `v2`, `v3`: intermediate operation records after reduced sheen, sparse strands and broader edit
  influence. They are historical output records, not current implementation acceptance.
- `portrait-context`: first whole-image context. Reviewers found that the symmetric width covered
  shoulder/sleeve, the root formed a little cap and the long shape still read as a plate.
- `portrait-context-v3`: one-sided width restored sleeve exposure; this intermediate has no separate
  independent visual verdict. Do not infer a pass.
- `portrait-context-v4`: crown-rooted sloping support. Both fresh reviewers found a conspicuous
  horizontal exposure boundary and unclear root, despite improved shoulder visibility. Source
  inspection explains the slope crossing the constant-depth hat at a screen-horizontal line.
- `portrait-context-v5`: root moved into its host; support kept behind face/fringe and ahead of the
  hat. Both fresh reviewers still found root ownership unclear, a rigid leaf/strip appearance and
  competing old hair layers. Sleeve/arm visibility and curvature improved, but the integration failed.

Reviewer observations are bounded image readings, not proof of physical discontinuity. For example,
v5's “starts at the eye” is a perceptual reading: the source root is inside the head and is occluded.
The discrepancy matters; hidden connection alone does not make the visible grouping legible.

## Decision from the failures

Pause more root/colour tweaks in this legacy assembly. It contains an unchanged face-side strip,
outer back curtain and separately routed left hair. Test the new part in a clean head/hairstyle
context so root, main mass and subordinate locks have an intelligible common organization. Return
to the portrait after that method works. The primitive's isolated default remains provisional.

Keep the useful tool corrections: visible selection, protected terminals, stale-state refusal,
one-sided width, and gesture sweep independent of thickness. These have actual operation evidence.
They do not compensate for a failed picture.
