This is not proof of learning merely because a source is named. The roadmap owns product milestones and gates; this map records method coverage. Reassess relevant sources during work packages and update this map in place when evidence changes. Do not rewrite historical tickets or append history here.

## Use protocol

For each selected method, record source location, the concrete drawing question, local prior-art baseline, rule adapted, output artifact, changed condition, causal contrast/failure, and what is not transferred. A teaching card or test supports but never substitutes for the visible artwork. Do not infer method acceptance from vendor QA or source reading alone. Update dispositions only against inspectable project evidence and final artifact revision.
