# 16 — L8 withdrawal B: draw a new subject from intent alone

Status: ready-for-agent (blocked)
Blocked by: 15-withdrawal-a

## Issue

The end goal is drawing with no reference at all (P18). After L7 proves recall of a known subject,
this rung proves generation: a subject never drawn in this project, described only in the language.

Composition knowledge becomes a first-class need here (SA1 finding 7): for a new subject, *someone*
must set the frame — focal point, thirds, horizon height, value key, figure-ground. The teacher role
as defined assumes a reference exists; this rung is where composition anchors (frame thirds, horizon,
focal point) enter the taxonomy, because now they are demanded.

## Scope

One new subject from intent alone (candidate: a still object with clear structure — a teapot, a
lighthouse; NOT a face — the face canon set is reference-tuned and would mask composition gaps).
Composition stated as relations to frame regions (thirds, centre, horizon), not frame-fractions.

## Acceptance

- [ ] no reference exists or is consulted (by construction)
- [ ] composition declared via frame-region anchors (thirds/horizon/focal), not raw fractions
- [ ] every value carries provenance (canon from vocabulary.md / taste with reason)
- [ ] fresh-eyes review: reads as the intended subject and as a competent drawing (P14 bar)
- [ ] gaps found feed back into `vocabulary.md` / the relation taxonomy with the drawing that
      demanded them — same-session doc updates (SSOT)
