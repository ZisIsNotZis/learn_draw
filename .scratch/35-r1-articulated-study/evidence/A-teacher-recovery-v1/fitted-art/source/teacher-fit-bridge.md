# A-only teacher-to-family bridge

This is a design-provenance bridge, not a pixel trace or claim that the reviewed observations uniquely determine garment geometry. The semantic gate verified the complete registered crop/topology map. Each family starts from the listed observation and relation, then a small editable parameter (or ratio/radius) defines its generated form. Runtime opens only `semantic-parameters.json`; it never reads this bridge or any teacher image/landmark.

## Parametric generation and spatial cause

1. `semantic-parameters.json` holds only named part-level design semantics, values and teacher observation IDs, not dense boundary coordinates. Each outline has at most four direct point anchors (many use only a center/radius or derived shared relation); additional vertices are sampled by analytic ellipse, eased curve, pinch, spline, taper or side/hem/opening rule.
2. `build_a.py` compiles the family parts, generated attachment boundaries and explicitly named depth-gradient `SupportFrame`s. The bodice/cap, cap/tube, and tube/cuff each reuse the same computed boundary in opposite directions; their support depth fields are solved from that edge so the paired local points meet in world space, while the surface has a finite depth gradient away from it. The cap/tube join is not drawn as a garment seam. Knot/loops/tails overlap only at the declared gather. No metadata-only attachment substitutes for shape contact.
3. Each local `(u,v)` point maps via `SupportFrame.local_to_world`, then the specified orthographic camera projects `(x,y,depth)`. The frame's horizontal/vertical axes preserve crop-aligned framing while finite depth offsets/slopes remain real world depth. The named cap/tube and garment-neighbor surfaces use adjacent planes with true shared world-space contact lines and differing off-seam depth, without asserting visible ink at the cap/tube contact. Opaque component fill faces go to `component_faces` → `vector_visibility.visible_regions`; semantic trim/fold paths go to `visible_segment_spans` using the same support-mapped faces. The renderer emits the adapter's depth-visible vector fills and only the surviving authored semantic strokes. Mesh diagonals are never ink and no visibility cut is authored.
4. Only after freezing this renderer/parameter interface is the teacher crop used by `scripts/draw check` for a side-by-side and diagnostic regions. No comparison metric changes the geometry. A future fresh visual reviewer receives the isolated image list, not this bridge, source, map or writer opinion.

The output is an A-only authored study candidate. This bridge and the teacher semantic PASS do not establish fitted-shape quality, art/readability, whole-R1 acceptance or user approval.
