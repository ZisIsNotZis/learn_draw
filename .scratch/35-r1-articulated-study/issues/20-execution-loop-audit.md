- **Finite stop already in force:** `.scratch/35-r1-articulated-study/issues/16-budget-exhaustion-checkpoint.md` records the bounded construction and one repair allowance exhausted, no more same-direction patches/renders, and explicitly says resource-blocked/unverified—not whole-goal failure. `.scratch/active-work.md` and `STATUS.md` likewise say no further same-direction patch/render. Older issue 14 authorization is superseded by this later stop; it is not a standing budget reset.
- **Prior correct implementation exists and has the exact requested guard:** `.scratch/35-r1-articulated-study/evidence/vendor-smooth-spatial/manifest.md` records the actual spatial support→world→camera→triangles→depth integration and `visible_segment_spans` line clipping, 8 tests including sampled self-crossing/touch/degeneracy rejection, four semantic controls, and reference-absent rendering. Yet its task explicitly limited it to interface proof and forbade changing R1 candidate/artwork. The authorized artifact directory was used for that module.
- **Latest garment candidate bypassed that reusable interface:** `evidence/curve-garment-application/source.py` imports `smooth_path` from the separate repository-root `evidence/vendor-smooth-study/study.py` (a standalone SVG utility), rather than importing the spatial module. Although it calls project geometry/depth APIs in `build()`, the SVG actually emitted by `main()` is hand-authored directly from `smooth_path`; it does not emit the support/depth-mapped geometry or use `visible_segment_spans` for its visible strokes. Its lines are direct SVG `L` strokes. Thus manifest/ticket claims of adapter use do not describe the generated final SVG path. The spatial module's self-intersection guard is not invoked here.
- **Coordinate-budget gap remains:** the garment source starts with four named anchors but `derive_controls()` adds more fixed offsets/absolute relation constants and emits eight curve points; the ticket/manifest explicitly acknowledge extra absolute constants and the unresolved <=4-coordinate budget. A four-name anchor dictionary alone is not proof that total authored geometry is compact.
- **Root evidence location violates the repeated ownership boundary:** `evidence/curve-garment-application/{source.py,ticket.md,manifest.md,check/}` is at repository root, while R1 ownership in spec is WP04 `work/artwork.svg`, `work/render_r1.py`, and its assigned evidence paths; issue 19 specifically corrected prior root `evidence/vendor-smooth-study/` placement by requiring `.scratch/35-r1-articulated-study/evidence/vendor-smooth-spatial/`. Root placement made the new artifact easy to mistake for the assigned R1 candidate and provided no revision-local ownership boundary. Nothing here moves or edits it.
- **Independent observations (source cited, not reinterpreted as an art verdict):** `/home/z/.pi/agent/sessions/--home-z-vibe-learn_draw--/subagent-artifacts/outputs/ee3d64d4-d28d-4d2e-9988-6e7992207723/r1/garment-application-image-observations.md` reports absent surrounding garment context, an unfinished outlined shape, an edge extending off-frame, and blank draft panes in regions 1–3; it notes those crops cannot establish missing detail. This audit cites the finding and checks its source mechanics, not pixels or artistic remedies.
- **Why the region panes are blank:** `scripts/draw.py::cmd_check` rasterizes the given SVG to its draft dimensions, resizes the supplied `--ref` crop to those dimensions, then selects identical pixel windows in that resized reference and draft. Here the supplied reference is a 410×370 garment crop; draft is a separate 720×600 SVG canvas with `viewBox="0 0 720 600"`. The report coordinates `(576,384)`, `(512,0)`, `(576,128)` are therefore crop-canvas coordinates, not root portrait `(x,y)` and not registered garment coordinates. The right pane is a crop from the SVG draft at those positions, where no artwork occurs in some regions. The source's canvas mapping `x=360+120*u`, `y=260-120*v` does not derive from the frozen crop registration. Resizing unequal-aspect crop and unrelated viewbox to common dimensions does not establish a meaningful spatial correspondence. So blank crops are explained by comparison/canvas mismatch, not proof that a default portrait-coordinate crop was applied; whole-frame check is likewise not valid evidence of local imitation. The image-only reviewer still correctly records that the provided full draft lacks readable local context.
- **Handoff/ownership cause evidenced:** the two-track contract names distinct WP03 construction interface and WP04 artwork ownership, but later task leaves authorized isolated studies and bounded outputs without a mandatory integrator-owned import seam or pre-render enforcement check. Issue 19 explicitly prohibited modifying R1 anchors/candidate; the garment leaf had a distinct scope, yet its author recreated a standalone path rather than consuming the already completed spatial adapter. Contracts stated constraints, but no enforceable handoff artifact named the sole library import API, locked candidate/evidence directory, or defined an automated rejection gate before image review. This is the substantiated mechanism for bypass, not a claim about an individual's intent. Short standalone leaves and repeated continuation authorization kept producing locally checkable demos instead of integrating the complete A/B deliverable; no verified integrator gate reconciled new evidence against current active state before another leaf was routed. That is a concrete ownership/interface/integration gap and a poor fit between leaf boundaries and the user's cohesive-art objective.

Separate independent reviewer sees only actual frozen image paths after assertions pass. A must preserve reference→imitation scope; B remains original mechanism transfer. Structural proof is necessary, never art acceptance. Keep hand/contact, collision, depth, heldout, review and user gates intact.
5. **Finite authorization:** do not roll forward an unbounded timer. Main should set one explicit bounded reset with a fixed wall-clock cap, max command duration, one integrated implementation/render, and at most one narrowly evidenced repair plus fresh independent review; halt at the cap and report blocked/unverified. Do not describe this audit as exhaustion of all viable routes.
