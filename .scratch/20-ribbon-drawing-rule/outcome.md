## Useful learning retained

- Complete UV perimeter plus depth visibility can be computed without mesh-edge ink or manual ranges.
  Finite-width ink can be clipped using a declared source-plane extension convention, including an
  external card. This is a bounded implementation, not a general line engine.
- **Correct visibility is not sufficient artistic line selection.** More perimeter lines can reduce
  clarity. Same local motif on both sides is likewise not sufficient to communicate the turn.
- **A physically correct edge-on event is not automatically a readable drawing.** All candidates
  shared the control's projection. This trial isolates two unsuccessful appearance rules; it does
  not prove a ruled-sheet family is incapable of good drawing, nor that all line approaches fail.
- XML validity, path equality, file presence and unit tests did not catch blank display. The actual
  inline-HTML/Chromium raster needed assertions on placement, nonempty ink and cached-vs-direct pixels.
